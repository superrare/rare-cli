# RARE Protocol CLI

The RARE Protocol CLI provides command-line workflows for RARE protocol contracts and API-backed flows. The TypeScript SDK is maintained separately in [`@rareprotocol/rare-sdk`](https://github.com/superrare/rare-sdk).

## Local Docs

- [CLI Reference](./cli/reference.md) is generated from the Commander command tree.
- [Compatibility shims](./compatibility-shims.md) documents the deprecated CLI package subpaths retained for existing SDK consumers.
- For SDK usage and API reference, see the [rare-sdk repository](https://github.com/superrare/rare-sdk#readme).

Regenerate and serve the docs locally with:

```bash
npm run docs:serve
```
